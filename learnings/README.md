## Adding a learning

An agent proposes a learning when something it found would have saved time or
a mistake in another project. Open a pull request to this repository:

- **One topic per file**, named by the topic (`ci-speed.md`, not
  `personal-coach-ci.md`). If a file on the topic exists, add to it.
- **Start with where it came from:** project and month ("Learned in Personal
  Coach (2026-10)"), and what happened, in a few lines with numbers.
- **Then the rules**, as short imperative bullets, and **Not wanted**.
- **Domain-neutral:** examples may come from the project, but the rule must
  make sense without it.
- Add a row to the table above, and say in the PR which projects should link
  it.

Keep files short; nothing here should need more than a few minutes to read.
